From install to a signed report

Everything runs on your machine. You need OBS (checked on 33.0.1), Python 3.10 or later, and an SSH key.

  1. Install it

    pipx install sponsifer

    Sponsifer is not on PyPI yet. Until it is, install it from a checkout, as the README describes.

  2. Switch on OBS's WebSocket server

    In OBS: Tools, WebSocket Server Settings. Sponsifer asks for its password only when OBS asks, uses it once and keeps it nowhere. OBS does not start the server in Safe Mode.

  3. Choose the key you sign with

    sponsifer key --ssh ~/.ssh/id_ed25519

    It prints your key's fingerprint. Put that fingerprint in your sponsorship agreements. It is how a sponsor knows a report is yours: a valid signature by any other key proves nothing. Sponsifer never reads your private key; OpenSSH signs, so passphrases and hardware keys work as usual.

  4. Open the app and record the deal

    sponsifer app

    Record a won deal in the Deals or Ads tab, with the sponsor's logo and wording. The app also prices a sponsorship and judges an offer, if you want it to.

  5. Put the sponsor into OBS

    sponsifer setup dl-104
sponsifer status

    setup makes four browser sources if they are missing (corner emblem, lower third, segment slate, break card), hidden and at the canvas size, and points the ones you have at this deal. Your scenes are built once; the sponsor is what changes. status checks the wiring and writes nothing. Every placement carries "Ad" and never shows a price.

    For a panel inside OBS, sponsifer dock gives the address to add under Docks, Custom Browser Docks.

  6. Go live, and log

    sponsifer log dl-104

    Or press Start in the dock. On air means the stream is live and the placement is in the program feed; a recording alone does not count. Events are prompts and OBS is asked directly every few seconds; where the two disagree, the direct answer counts and the disagreement is written down.

  7. Sign the report, and send it

    sponsifer report dl-104 --vod https://www.twitch.tv/videos/…

    Send the sponsor the three files it names. They can check them on this site's report checker, or with ssh-keygen using the lines in the notice. Twitch keeps a past broadcast for 7 days, 14 for Affiliates and 60 for Partners, so send it promptly.

Without a sponsor

sponsifer log --label stream-1102 --source "Webcam" times any source, and sponsifer report --label stream-1102 signs it as an airtime report.

What it cannot see

  • The recording is the evidence. The report only says where to look in it.
  • OBS says whether a source is in the program, not on which canvas. With a second canvas running, as Twitch's Dual Format does for vertical video, the log cannot say which feed a placement was in, and the report says so.
  • A logger that joined after the stream began cannot give offsets into the recording; the report says that too.
